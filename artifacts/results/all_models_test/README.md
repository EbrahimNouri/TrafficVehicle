# All-model test diagnostic

Generated by `scripts/evaluate_all_models_on_test.py` from `configs/paths.json`.

**These numbers are diagnostic only.** The production model was selected on
validation macro-F1 and evaluated on the frozen test set exactly once; that
official result in `artifacts/results/frozen_test_evaluation.json` is
authoritative and unchanged. These extra per-model test scores exist for
error analysis. Selecting a different model on the basis of this file would
turn the test set into a tuning set and void the leakage guarantees, so it must
not be done.

## Files

| File | Contents |
| --- | --- |
| `summary.json` | Full metrics per experiment, plus the integrity check and protocol echo |
| `summary.csv` | One row per experiment, ranked by test macro-F1 |
| `per_image_predictions.csv` | Every model x every test image (5200 rows) |
| `per_image_predictions.jsonl` | The same rows as one JSON object per line |
| `per_model/<experiment>.csv` | One file per experiment (400 rows each) |
| `confidence_by_true_class.csv` | Confidence and accuracy per true class |
| `README.md` | This file |

## Columns in `per_image_predictions.csv`

| Column | Meaning |
| --- | --- |
| `model` | Experiment key from `experiment_results.json` |
| `architecture` | `traffic_cnn` or `resnet18` |
| `loss` | Training loss: `cross_entropy` or `bce` |
| `probability_kind` | `softmax`, or `sigmoid` for the `bce_loss` arm. Sigmoid outputs are not a distribution, so their `confidence` is a per-class score rather than a probability |
| `image_index` | Row index in the test split, in dataset order |
| `image_path` | Path relative to the repository root |
| `true_class` / `predicted_class` | Labels |
| `correct` | Whether the prediction matches the label |
| `confidence` | Score of the **chosen** class, i.e. the top-1 probability |
| `margin` | Top-1 minus top-2 score; a small margin means an ambiguous choice |
| `true_class_probability` | Score assigned to the correct label |
| `top3` | Best three classes as `class:score` separated by `\|` |
| `temperature` | Temperature applied to the logits. Only the production model uses its validation-fitted temperature; every other model uses 1.0 because no calibration was fitted for it |
| `below_official_review_threshold` | `confidence` under the production review threshold (0.8180). This is the *production* threshold shown for reference, **not** a per-model calibrated threshold |

## Integrity check

The production model's macro-F1 is recomputed here and compared with the locked
official value; the run aborts if they disagree by more than 1e-6.
Observed absolute difference: 0.000e+00.
